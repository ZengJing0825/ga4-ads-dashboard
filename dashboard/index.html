Data Refresh Pipeline

Trigger
Daily 09:00 / 14:00 (local) via macOS launchd
Scope
Regenerates dashboard/data.json only; index.html is static
09:00 launchd trigger
  ├─ Lock file check (PID-based, stale detection)
  ├─ 300s timeout watchdog
  ├─ Backup data.json (keep last 7)
  │
  ├─ [1/4] fetch_ga4.py          ← GA4 Data API, 30 days, funnel events
  │      fail → retry 3x (10s/20s/40s) → exit
  │
  ├─ [2/4] fetch_google_ads.py  ← Ads API, 30 days, campaigns
  │      fail → retry 3x → soft-fail (use cache)
  │
  ├─ [3/4] Merge → dashboard/data.json
  │
  └─ [4/4] validate_data.py
         fail → restore backup + macOS notification
